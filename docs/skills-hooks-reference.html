스킬은 3계층으로 나뉩니다. ① 이 저장소의 skills/ — weed-harness 플러그인으로 배포되는 스킬, ② ~/.claude/skills/ — 플러그인과 무관하게 로컬에 직접 설치된 스킬, ③ superpowers·ouroboros 등 다른 플러그인이 제공하는 스킬(이 문서 범위 밖).

훅은 이 저장소의 hooks/에 스크립트로 보관되고, settings.json(사용자 전역)과 hooks.json(플러그인)에 이벤트별로 등록되어 실행됩니다.

플러그인으로 패키징되는 10개 — Claude용 8개 + Codex 전용 2개(matt-*). Codex 협업 파이프라인(refine-plan, goal-set, team-*), devlog, type-graph, context-budget, merge-resolve, deploy-verify는 2026-07-30 정리에서 제거되었습니다.

2. 로컬 스킬 (~/.claude/skills/)

플러그인 배포와 무관하게 직접 설치된 스킬. 2026-07-30 정리에서 미사용 스킬 5개(browse, qa, scrape, diagram, karpathy-guidelines)는 skillOverrides로 비활성화되어 4개만 활성 상태입니다.

스킬출처역할
orca-cliOrca orca CLI로 Orca가 관리하는 worktree·터미널·자동화·내장 브라우저를 조작. 다른 에이전트로의 완전한 핸드오프(handover)에도 사용.
orchestrationOrca Orca 멀티에이전트 조율 — 스레드 메시지, ask/reply 블로킹 플로우, 태스크 DAG, 의사결정 게이트, 코디네이터 루프.
computer-useOrca Orca의 computer-use CLI로 로컬 데스크톱 앱 창을 접근성 트리·스크린샷·안전한 UI 액션으로 검사·조작.
graphify독립 모든 입력(코드·문서·논문·이미지)을 영속 지식 그래프로 변환. graphify-out/이 있으면 코드베이스 질문을 그래프 쿼리로 먼저 처리해 토큰 절약. pip 패키지 graphifyy로 배포.

3. Hooks (hooks/)

이벤트에 자동 반응하는 스크립트 3개. OMC 훅(omc-skill-filter), Codex 리뷰 훅(codex-task-review), devlog 계열(devlog-hook, tsg-bash-failure), merge-conflict-trigger, gstack-skill-filter는 정리 완료로 삭제됐습니다.

훅이벤트역할
graphify-claudemd-inject.shPostToolUse: Skill /graphify 스킬 실행 후 프로젝트 CLAUDE.md에 graphify 운용 섹션을 자동 주입.
auto-update.shSessionStart 필수 스킬 자동 업데이트 — PyPI에 graphifyy 신버전이 있으면 업그레이드 후 claude·codex 양쪽에 스킬 재설치, superpowers 플러그인 업데이트(best-effort), matt-* codex 스킬 재동기화. 실패해도 세션 시작을 막지 않음.
language-rule.shUserPromptSubmit 매 프롬프트마다 언어 규칙 리마인더 주입 — 사용자 보고/대화는 한국어, 코드·주석·커밋 메시지는 English.
hooks.json플러그인 등록 weed-harness 플러그인이 설치될 때 등록되는 훅 선언. Codex 리뷰 훅 제거 후 현재는 빈 선언("hooks": {}) — 모든 훅은 /setup을 통한 opt-in 등록.
실제 등록 위치 — settings.json vs hooks.json

같은 스크립트라도 어디에 등록되느냐에 따라 적용 범위가 다릅니다.

  • settings.json (사용자 전역) — 모든 세션에 적용:
    • UserPromptSubmit language-rule.sh
    • SessionStart skill-subscribe/scripts/check.py --hook (업스트림 스킬 업데이트 확인) + auto-update.sh (필수 스킬 자동 업데이트)
  • hooks.json (플러그인) — Codex 리뷰 훅 제거 후 빈 선언. 플러그인이 자동 등록하는 훅은 없음.
  • graphify-inject 훅은 /setup 스킬이 사용자 설정에 등록해 주는 방식입니다.

참고: 리포의 settings.json은 업스트림에서 vendored된 파일이라 /home/weed/ 경로가 남아 있습니다 — 로컬 설정 원본이 아닙니다.

🔄

훅이 만드는 자동화. 매 프롬프트마다 language-rule이 언어 규칙을 상기시키고, /graphify 실행 후에는 CLAUDE.md에 운용 섹션이 자동 주입됩니다. 세션이 시작될 때마다 auto-update가 필수 스킬(graphify claude+codex, superpowers, matt-*)을 자동으로 최신화하고, skill-subscribe가 구독 스킬 업데이트를 알립니다.
