# matt-loop for Codex

This package exposes the matt loop (`matt-interview`, `matt-orchestrator`) for Codex.

Run `$matt-interview` when a feature, bug fix, or refactor is underspecified; hand the ready spec to `$matt-orchestrator` for supervised multi-track execution with Matt Pocock skills. When a skill mentions Claude-specific hooks, slash commands, or `~/.claude` paths, treat that as Claude-oriented guidance rather than a guaranteed Codex runtime feature.

This Codex package does not ship the repository's Claude hook automation.
